Changelog

v1.1.5 latest 2026-11-08
  • Added meter_lut.c/h: lookup tables and decoder for energy meter input registers (FC04, addresses 2–362) and holding registers (FC03, addresses 1316–65305). Supports float32, uint32, uint16, and ascii4 register types.
v1.1.4 2026-11-07
  • BOOTSEL button held for 3 seconds at runtime resets WiFi portal password to default ("inverter") and reboots. No PC or serial terminal required.
v1.1.3 2026-11-07
  • Added wifi-reset command to the emergency USB config shell — resets WiFi portal password to "inverter" and reboots.
v1.1.2 2026-11-07
  • Removed boot-time USB port detection wait (was up to 15 s). WiFi config portal now starts immediately at every boot regardless of what is plugged into USB.
  • Emergency USB config shell retained as backup (DTR held 2 s with no inverter traffic).
v1.1.1 2026-11-07
  • WiFi AP authentication mode reverted to WPA2-MIXED. WPA2-AES-only was preventing some phones and laptops from connecting to the INVConfig portal.
v1.1.0 2026-10-17
  • Firmware version now shown on the status page.
  • Modbus exception response sent to GivTCP on RTU failure instead of a silent drop.
  • TCP receive changed to single fixed-size read to avoid partial-frame processing.
  • Watchdog updated inside USB CDC read-idle loop to prevent reset during slow inverter polling.
  • Debug output moved to ring buffer — UART hex-dump removed from hot path.
Manual flash via USB
Use when OTA is not available or as a recovery method.
  1. Download the .uf2 file above.
  2. Hold BOOTSEL on the Pico while plugging it into a PC. A drive called RPI-RP2 appears.
  3. Copy the .uf2 file onto that drive. The Pico reboots automatically.
  4. Reconnect the USB cable to the inverter.

Your Ethernet IP settings and WiFi portal password are preserved across updates.
